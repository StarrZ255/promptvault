PROMPTVAULT

Coffre-fort local et sécurisé pour vos prompts IA.

PromptVault est une application de bureau conçue pour centraliser, organiser et sécuriser vos meilleurs prompts (instructions pour IA). Toutes vos données sont stockées localement sur votre machine.

TELECHARGEMENT ET INSTALLATION

Si vous voulez simplement utiliser l'application sans coder :

1. Allez sur la page des Releases (https://github.com/USER/REPO/releases/latest).
2. Dans la section Assets, téléchargez le fichier finissant par .exe.
3. Lancez l'installateur et suivez les instructions.
4. Utilisez Ctrl + Shift + P pour ouvrir le hub n'importe où.

FONCTIONNALITES CLES

Launcher Hub (Ctrl + Shift + P) : Une interface rapide et élégante pour copier vos prompts sans quitter votre navigateur ou votre éditeur.
Capture Rapide (Alt + N) : Enregistrez instantanément une idée ou un prompt trouvé sur le web via une fenêtre flottante légère.
Suggestion Intelligente : Lors d'un copier-coller, l'application analyse le texte pour vous suggérer automatiquement un titre, une thématique et des tags.
Gestion par Thématiques : Organisez vos prompts par catégories personnalisables.
Confidentialité Totale : Pas de cloud, pas de compte. Vos données restent sur votre disque.

GUIDE DU DEVELOPPEUR
